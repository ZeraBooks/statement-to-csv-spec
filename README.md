# Statement to CSV spec

Column layouts and sample files for turning bank and card statements into
spreadsheet rows that can be checked against the statement's printed balances.
All figures are fictional.

| Folder | What it is | Guide |
|---|---|---|
| `google-sheets/` | A standard layout for statement rows in Google Sheets, with a sample file | [Bank statement to Google Sheets](https://www.zerabooks.com/bank-statement-to-google-sheets) |
| `credit-cards/` | Card statement rows with charges negative and payments positive, a tie-out formula and a sample that ties | [Credit card statement to Excel](https://www.zerabooks.com/credit-card-statement-to-excel) |

Maintained by [ZeraBooks](https://www.zerabooks.com).
